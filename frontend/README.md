# ExpenseFlow: frontend

Interface em Next.js, React e Tailwind CSS. A visão geral do projeto, como rodar tudo e as decisões técnicas estão no [README da raiz](../README.md).

## Comandos

```bash
npm run dev     # servidor de desenvolvimento (porta 3000)
npm run build   # build de produção
npm run start   # serve o build de produção
npm run lint    # análise estática
```

## Configuração

Copie `.env.example` para `.env.local` e aponte `NEXT_PUBLIC_API_URL` para o backend (padrão: `http://localhost:3001`).
